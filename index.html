Case studies

Lead response for clinics

Problem
Clinics lose patients who fill a form or write after hours and wait too long for an answer.
What I built
A worker that answers every new website lead with a personal reply and a booking link, reads the calendar to know who booked, and sends one follow-up after 24 hours only to people who didn't. I ran it on my own site first.
Stack
PythonRailwayGmail APIGoogle CalendarClaude
~4 minutes from form to reply in the end-to-end test, booking detected correctly, no follow-up sent to people who booked. The test also caught an old calendar still embedded on the contact page.

CV screening for a recruiter

Problem
A recruiter's inbox mixed applications for several vacancies with everything else, and reading every CV took days.
What I built
An app that reads the inbox, detects the vacancy from each email, extracts the CV and ranks candidates with strengths and gaps. It tracks which date range has been covered, measured against the mail server.
Stack
PythonIMAP / Gmail OAuthClaudeDesktop app (WebView2)Web version
First run on the real inbox: 30 emails, 30 CVs sorted into the right vacancies. A 100-email batch found 45 CVs for about $0.25 in model cost.

Job application co-pilot

Problem
Applying to jobs means filling the same long forms again and again, and AI tools that tailor CVs tend to invent achievements.
What I built
A desktop app that scores a CV against a vacancy, tailors it without adding facts, and fills application forms in a real browser. It stops before Submit by design; anything it doesn't know is left as a question for the person.
Stack
PythonPlaywrightClaudePyInstaller
26 to 70 seconds and $0.05 to $0.12 per form. After fixing the CV parser the score finally separates fits: 32-39 on a mismatched vacancy, 80-82 on a matching one.

Research tables that check themselves

Problem
A research team built the results tables of a technical report on rural water and sanitation by hand from a large dataset. One wrong number spreads through the whole document.
What I built
A pipeline that audits the raw data, builds every table, and verifies the output with checks written separately from the code that builds it, so a misunderstanding can't confirm itself. It also finds exact arithmetic relations between columns automatically.
Stack
PythonpandasSciPyWord outputDesktop app
63 of 63 checks pass and the delivered report is reproduced with zero differences, in under 30 seconds.

An orchestrator for a team of agents

Problem
Separate bots for WhatsApp, leads, ads and content meant separate places to operate and nobody watching the whole.
What I built
A manager agent that delegates to 8 specialists, with shared memory in Postgres, a web console, a confirmation gate against prompt injection, and a health check that runs in CI against production. Prices and events can be changed from chat and the WhatsApp bot picks them up without a deploy.
Stack
PythonNodeClaude tool usePostgresRailwayGitHub ActionsMeta Cloud API
73 actions across 8 agents, live 24/7. A config change from chat reached the live bot in ~30 seconds. The security smoke tests caught 10 of 10 deliberately broken defenses.

A contact list from public sources and a contact database, a short letter, and a sending run from the client's own mailboxes. The contact data stayed out of version control.
